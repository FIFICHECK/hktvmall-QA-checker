❓ 教學及注意事項

🚀 SKU 自動擷取（首選模式）

  1. 喺 SKU ID 輸入框貼上產品 SKU（例如 B0185001_S_EUB_7114）
  2. Click「🔍 自動檢查」
  3. 系統會自動 Fetch HKTVmall 頁面，拆解成 5 部份 逐項檢查
  4. 如果有安裝 Extension，會自動提取產品圖片做 OCR

✏️ 手動輸入模式（Fallback）

  1. Copy 產品名稱、簡介等文字貼上相應欄位
  2. Upload 產品圖片到「包裝圖片檢查」
  3. Click「📸 OCR 讀取 & 檢查」或「🔍 檢查輸入內容」

📦 Batch 批量檢查

  • 每行一個 SKU ID
  • 系統會逐個 Fetch，有 rate limit 請耐心等候
  • 亦可以 Upload CSV 進行批量檢查

🔌 Browser Extension（推薦）

  • 安裝 Extension 後可直接從 Browser DOM 提取產品資料
  • 解決 CORS proxy 限制，令圖片檢查正常運作
  • 安裝方法：Click「🔌 裝 Extension」跟指示做

📋 檢查結果點睇

  • 🔴 高風險 — 可能違規，建議立即修改
  • 🟡 中度風險 — 需留意，建議跟指引修正
  • 🟢 安全 — 已符合要求
  • 每個違規都會有 引用條例 + 修改建議

⚠️ 重要聲明

此工具僅供參考，唔構成法律意見或代表 HKTVmall QA 立場。

所有檢查結果只作為參考性質，一切以 QA 為準。

如有疑問請填寫 MCS 表格 或直接聯絡 QA 部門 查詢。
